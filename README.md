# Minseo (Eric) Kim - GitHub Pages Site

Static academic homepage based on the public Google Sites profile:

<https://sites.google.com/view/minseo-eric-kim>

## Files

- `index.html` - one-page academic homepage
- `styles.css` - visual system and responsive layout
- `script.js` - navigation, publication filtering, email copy action
- `assets/` - SVG favicon and profile mark
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## Deploy To GitHub Pages

1. Create a repository named `<github-username>.github.io`.
2. Copy these files into the repository root.
3. Commit and push to the `main` branch.
4. Open `https://<github-username>.github.io` after GitHub Pages finishes publishing.

For a project repository instead of a user site, push these files to any repo and enable
Pages from `Settings -> Pages -> Deploy from a branch -> main / root`.
